# SPAIK DNS SWITCHER

Удобная Windows-программа для быстрого переключения DNS-профилей. Она показывает активный DNS, проверяет задержку серверов, умеет выбирать самый быстрый вариант и возвращать автоматические настройки DHCP.

## Возможности

- выбор активного сетевого адаптера;
- применение готовых DNS-профилей;
- включение DNS over HTTPS для профилей с подтверждённым шаблоном;
- проверка задержки всех DNS-серверов;
- автоматический выбор самого быстрого профиля;
- восстановление DNS, получаемого по DHCP;
- автоматическая очистка DNS-кэша после изменения настроек.

## Системные требования

- Windows 10 или Windows 11;
- права администратора для изменения сетевых настроек;
- Python 3.10+ — только для запуска из исходников или сборки EXE.

## Запуск готовой версии

1. Скачайте `SPAIK-DNS-SWITCHER.exe` со страницы **Releases**.
2. Запустите файл.
3. Подтвердите запрос Windows на права администратора.
4. Выберите сетевой адаптер и нужный DNS-профиль.

> Программа изменяет системные настройки DNS. Перед использованием убедитесь, что выбранные DNS-серверы подходят вам и доступны из вашей сети.

## Запуск из исходников

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

## Сборка EXE

Запустите `BUILD_EXE.cmd`. Скрипт создаст отдельное виртуальное окружение, установит PySide6 и PyInstaller и положит результат в папку `dist`.
Версия PySide6 закреплена в `requirements.txt`, который использует и скрипт сборки:
это позволяет повторить проверенную Windows-сборку с теми же Qt DLL.

## Встроенные профили

- Comss.one;
- Xbox DNS;
- Malw DNS;
- GeoHide DNS.
- dns.bezmezhau.com — `143.20.64.55`, `31.58.216.201`;
- dns.mafioznik.xyz — `103.27.157.38` (один подтверждённый IPv4).

Для новых профилей используются DoH-шаблоны
`https://dns.bezmezhau.com/dns-query` и `https://dns.mafioznik.xyz/dns-query`.
Имена профилей не подставляются в настройки адаптера: Windows получает указанные
IPv4-адреса, а при включённом DoH — соответствующий HTTPS-шаблон для каждого IP.
В тестировании задержки и выборе самого быстрого DNS участвуют оба новых профиля.
Для одиночного сервера не добавляется DNS другого провайдера в качестве запасного.

После применения программа считывает адреса обратно из Windows и сообщает об ошибке,
если они не совпадают с выбранным профилем. Ошибка настройки DoH также показывается
явно: применение обычного DNS не означает, что шифрование успешно включилось.

Адреса Bezmezhau опубликованы в [инструкции провайдера для Windows](https://bezmezhau.com/en/setup/windows).
Адрес Mafioznik соответствует A-записи `dns.mafioznik.xyz`; актуальность и сетевую
доступность нужно проверять отдельно — наличие профиля не гарантирует доступ к ИИ.

Адреса и доступность сторонних DNS-сервисов могут меняться. Проект не связан с владельцами перечисленных сервисов.

## Проверка изменений

```powershell
python -m unittest discover -s tests -v
```

Тесты проверяют сохранность прежних профилей, применение новых профилей через кнопки
интерфейса, точные команды PowerShell/netsh, DoH, выбор самого быстрого сервера и
обработку ошибок Windows. Системные команды в тестах заменены заглушками:
DNS компьютера и пользовательские настройки при запуске тестов не меняются.

## Безопасность

Программа выполняет только локальные команды Windows для чтения и изменения DNS-настроек, настройки DoH и очистки DNS-кэша. Исходный код находится в файле `main.py` и доступен для проверки.
